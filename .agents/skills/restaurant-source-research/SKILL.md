description: Discover and extract official restaurant menu, nutrition, serving and customization evidence for a Macro Maxxer import.
---

Start with the central command in [the import workflow](../../../docs/phase-3/import-workflow.md). Use research-only mode when no extraction adapter is available. Read the discovery gaps and extraction coverage and source statuses before suggesting any further collection. A failed or gated source needs a new official lead or manual review. Continue using evidence from other sources captured in the run.

Use replay when available. Obtain authorization for live collection and keep browser collection passive. See the [discovery](../../../docs/phase-2/source-discovery.md) and [extraction](../../../docs/phase-2/extraction.md) guides for source rules and standalone diagnostics. Give Developer the run ID and evidence paths. Preserve URLs, source timestamps, hashes and record locators. An information request can be drafted for the owner to review.
